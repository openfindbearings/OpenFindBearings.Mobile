# Mobile BFF 缓存与限流策略 v1.0.0

## 概述

Mobile BFF 作为移动端唯一公网入口，需要合理的缓存和限流策略保护后端服务、提升用户体验。

## 变更日志

### v1.0.0 (2026-09-01)

- 初始版本，缓存策略、限流方案、降级处理。

## 缓存策略

### 当前实现

BFF 当前无主动缓存，每次请求透传到 API。后续可按需增加。

### 建议缓存层

| 端点 | 缓存策略 | TTL | 说明 |
|------|----------|-----|------|
| `/mobile/home` | 内存缓存 | 5 分钟 | 热门轴承/推荐商家变化不频繁 |
| `/mobile/config` | 内存缓存 | 30 分钟 | 站点配置极少变化 |
| `/mobile/bearings/search` | 不缓存 | - | 搜索结果随关键词变化 |
| `/mobile/bearings/{id}` | 内存缓存 | 10 分钟 | 详情页变化不频繁 |
| `/mobile/merchants/search` | 不缓存 | - | 搜索结果随关键词变化 |
| 认证端点 | 不缓存 | - | 登录/刷新不可缓存 |

### 实现建议

使用 `IMemoryCache`（单实例内存缓存），BFF 为单 Pod 部署，无需分布式缓存。

```csharp
// Program.cs 中注册
builder.Services.AddMemoryCache();

// 端点中使用
group.MapGet("/home", async (IMemoryCache cache, ApiClient api) =>
{
    if (cache.TryGetValue("home", out var cached))
        return Results.Ok(cached);

    // 并行请求 API
    var result = await AggregateHomeData(api);
    cache.Set("home", result, TimeSpan.FromMinutes(5));
    return Results.Ok(result);
});
```

## 限流策略

### 当前实现

BFF 当前无限流中间件。生产环境应加限流保护。

### 建议限流规则

| 端点分类 | 限流策略 | 说明 |
|----------|----------|------|
| 认证端点（login/send-code） | 按 IP，10 次/分钟 | 防暴力破解 |
| 公开端点 | 按 IP，100 次/分钟 | 防爬虫 |
| 需登录端点 | 按用户，60 次/分钟 | 防滥用 |

### 实现建议

使用 ASP.NET Core 内置限流（`Microsoft.AspNetCore.RateLimiting`）或第三方库。

```csharp
// 简易滑动窗口限流中间件
app.UseRateLimiter(new RateLimiterOptions
{
    GlobalLimiter = PartitionedRateLimiter.Create<HttpContext, string>(context =>
        RateLimitPartition.GetSlidingWindowLimiter(
            partitionKey: context.Connection.RemoteIpAddress?.ToString() ?? "unknown",
            factory: _ => new SlidingWindowRateLimiterOptions
            {
                PermitLimit = 100,
                Window = TimeSpan.FromMinutes(1),
                SegmentsPerWindow = 6,
            })),
});
```

## 降级策略

### API 不可用时的处理

| 场景 | 处理方式 |
|------|----------|
| API 返回 5xx | BFF 透传 503，前端显示"服务暂不可用" |
| API 超时（>5 秒） | BFF 返回 504，前端显示"请求超时" |
| Identity 不可用 | 认证端点返回 503，前端提示"登录服务暂不可用" |
| 部分聚合失败 | `/mobile/home` 返回已获取的数据，缺失字段填空数组 |

### 健康检查

BFF 暴露标准健康端点供 K8s 探针使用：

| 路径 | 类型 | 用途 |
|------|------|------|
| `/health` | 基础 | 服务存活 |
| `/health/live` | Liveness | K8s 存活探针 |
| `/health/ready` | Readiness | K8s 就绪探针 |

## 错误码规范

| HTTP 状态码 | 含义 | 前端处理 |
|-------------|------|----------|
| 200 | 成功 | 正常渲染 |
| 400 | 请求参数错误 | 提示用户检查输入 |
| 401 | 未登录/token 过期 | 尝试刷新 token，失败跳登录 |
| 403 | 无权限 | 提示权限不足 |
| 404 | 资源不存在 | 显示空状态 |
| 500 | BFF 内部错误 | 提示"服务异常" |
| 503 | 后端服务不可用 | 提示"服务维护中" |
