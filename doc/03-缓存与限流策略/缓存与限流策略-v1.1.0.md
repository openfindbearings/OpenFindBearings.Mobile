# Mobile BFF 缓存与限流策略 v1.1.0

## 概述

Mobile BFF 作为移动端唯一公网入口，需要合理的缓存和限流策略保护后端服务、提升用户体验。

## 缓存策略

### 当前实现

BFF 当前无主动缓存，每次请求透传到 API。后续可按需增加。

### 建议缓存层

| 端点 | 缓存策略 | TTL | 说明 |
|------|----------|-----|------|
| `/mobile/home` | 内存缓存 | 5 分钟 | 热门轴承/推荐商家变化不频繁 |
| `/mobile/bearings/{id}` | 内存缓存 | 10 分钟 | 详情页变化不频繁 |
| `/mobile/bearings/search` | 不缓存 | - | 搜索结果随关键词变化 |
| `/mobile/merchants/search` | 不缓存 | - | 搜索结果随关键词变化 |
| 认证端点 | 不缓存 | - | 登录/刷新不可缓存 |

### 实现建议

使用 `IMemoryCache`（单实例内存缓存），BFF 为单 Pod 部署，无需分布式缓存。

## 限流策略

### BFF 限流（已实现）

BFF 使用 ASP.NET Core 内置 `RateLimiter` 中间件，仅对认证端点组（`/mobile/auth/*`）执行固定窗口限流：

| 端点组 | 策略 | 阈值 | 说明 |
|--------|------|------|------|
| `/mobile/auth/*` | 按来源 IP，固定窗口 | 10 次/分钟 | 防暴力破解登录/注册/刷新 |
| 其他端点 | 无限流 | - | 公开端点无限制，需登录端点靠 JWT 过期保护 |

被拒响应：
```json
{ "success": false, "code": "RATE_LIMITED", "message": "操作过于频繁，请稍后再试" }
```

### API 限流白名单（已实现）

API `RateLimitingMiddleware` 根据用户类型执行滑动窗口限流（配置从 SystemConfig 表动态读取），同时维护三层白名单：

| 白名单 | 路径/条件 | 原因 |
|--------|-----------|------|
| 健康检查 | `/health`, `/health/ready`, `/health/live`, `/healthz`, `/readyz` | K8s 探针不应被限流 |
| Sync 接口 | `/api/sync/*` 前缀 | 机器间通信（Sync→API），非用户流量 |
| 内部令牌 | `X-Internal-Token` 匹配 `Internal:ApiToken` | BFF→API 单 Pod IP 转发，按 IP 限流会误伤聚合流量 |

**内部令牌豁免原理**：API 无公网 ingress，所有 App 流量经 BFF 单一 Pod IP 转发。若按来源 IP 执行 guest 限流（30/min），正常浏览即触发 429。BFF 请求携带匹配的 `X-Internal-Token` 头时跳过用户级限流，边缘限流由 nginx/BFF 承担。

令牌经 K3s ConfigMap 注入 API 与 BFF 两侧，必须同值（`Internal:ApiToken`）。

## 降级策略

### API 不可用时的处理

| 场景 | 处理方式 |
|------|----------|
| API 返回 5xx | BFF 透传 503，前端显示"服务暂不可用" |
| API 超时（>5 秒） | BFF 返回 504，前端显示"请求超时" |
| Identity 不可用 | 认证端点返回 503，前端提示"登录服务暂不可用" |
| 部分聚合失败 | `/mobile/home` 返回已获取的数据，缺失字段填空数组 |

### 健康检查

BFF 暴露标准健康端点供 K8s 探针使用：

| 路径 | 类型 | 用途 |
|------|------|------|
| `/health` | 基础 | 服务存活 |
| `/health/live` | Liveness | K8s 存活探针 |
| `/health/ready` | Readiness | K8s 就绪探针 |

## 错误码规范

| HTTP 状态码 | 含义 | 前端处理 |
|-------------|------|----------|
| 200 | 成功 | 正常渲染 |
| 400 | 请求参数错误 | 提示用户检查输入 |
| 401 | 未登录/token 过期 | 尝试刷新 token，失败跳登录 |
| 403 | 无权限 | 提示权限不足 |
| 404 | 资源不存在 | 显示空状态 |
| 429 | 限流 | 等待后重试 |
| 500 | BFF 内部错误 | 提示"服务异常" |
| 503 | 后端服务不可用 | 提示"服务维护中" |
